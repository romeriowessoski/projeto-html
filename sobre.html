Projeto de Desenvolvimento Web

Este projeto foi criado durante as aulas do curso de desenvolvimento web.

Inicialmente trabalhamos com HTML semântico para organizar corretamente a estrutura da página.

Depois adicionamos CSS, Box Model, layout fluido, Mobile-First, Flexbox, Grid e acessibilidade.

Agora o projeto também utiliza JavaScript para adicionar comportamento e interatividade.

Tecnologias utilizadas

HTML

Responsável pela estrutura e pelo conteúdo da página.

CSS

Responsável pela aparência, layout e responsividade.

JavaScript

Responsável pelos filtros, busca, seleção e validação do formulário.
